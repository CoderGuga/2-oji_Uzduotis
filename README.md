Čia yra pateikti visi programos naudojami failai, tačiau taip pat yra pridėtas windows operacinėje sistemoje veikiantis .exe failas dėl patogumo.

Atsidarius programą, jus pasitiks meniu kuriame galėsite pasirinkti ką norite vykdyti.
Įvedus 9, programa automatiškai išbandys visus "rule of 5" metodus ir perdengtus įvedimo ir išvedimo operatorius (tiek terminale, tiek iš failo).
